Connectors give your agents access to external services and tools. Octop groups them into **built-in connectors** — ready-made integrations you authorise once — and **custom connectors**, which are MCP servers you point Octop at yourself. Connectors are configured at the account level; during a conversation you pick which ones the agent may use.

## Built-in connectors

Octop ships 18 built-in connectors:

| Connector | What it provides |
|---|---|
| **Tencent Docs** | Read and write Tencent Docs, smart sheets, and workspace files |
| **Tencent IMA** | Read, write, search, and manage notes and knowledge bases |
| **Tencent Meeting** | Meeting management, lookup, recording, and AI minutes |
| **Tencent News** | News search and topic subscriptions |
| **WeRead** | Bookshelf sync and reading notes |
| **Tencent Lexiang** | Knowledge base search, reading, authoring, and document management |
| **Tencent Weiyun** | Official MCP — file listing, upload, download, sharing, and management |
| **Personal mailbox** | Connect QQ Mail, NetEase Mail, Gmail, and others over IMAP/SMTP |
| **QQ Music** | Song search, charts, playlists, and listening reports |
| **Fliggy** | Flight, hotel, attraction, and itinerary search |
| **Baidu Maps** | Place search, route planning, and weather lookup |
| **Ctrip Wendao** | Hotel, flight, and itinerary Q&A |
| **Meituan travel assistant** | Hotels, flights, train tickets, attractions, and itinerary Q&A |
| **Yuandian** | Laws and regulations, case documents, company data, and legal hallucination checks |
| **Youdao Cloud Notes** | Official MCP — note creation, search, organisation, and management |

### Connect a built-in connector

<Steps>
  <Step title="Open Connectors">
    Navigate to **Connectors** in the sidebar and stay on the **Built-in connectors** tab.
  </Step>
  <Step title="Pick a service">
    Find the connector you want and click **Connect**.
  </Step>
  <Step title="Authorise access">
    Complete the authorisation flow. Octop stores the resulting token under `~/.octop/secrets/` — it never leaves your machine.
  </Step>
  <Step title="Select it in chat">
    Connectors are account-level. In a conversation, tick the connectors the agent should be able to use.
  </Step>
</Steps>

<Warning>
  Revoking authorisation from the external service invalidates the stored token. The agent reports a tool error the next time it tries to use that connector. Re-authorise from the Connectors page to restore access.
</Warning>

## Custom connectors (MCP)

The **Model Context Protocol (MCP)** is an open standard for connecting AI agents to external tool servers. Under **Connectors → Custom connectors** you can register any MCP-compatible server, either through the visual editor or by pasting JSON:

```json
{
  "deepwiki": {
    "display_name": "DeepWiki",
    "url": "https://mcp.deepwiki.com/mcp",
    "transport": "streamable_http"
  }
}
```

Two server types are supported:

| Type | When to use |
|---|---|
| **HTTP server** | The MCP server is reachable over a URL (for example `streamable_http`) |
| **Stdio server** | The MCP server runs as a local process that Octop launches |

<Note>
  A stdio server must be installed on the machine running `octop run`, and an HTTP server must be reachable from it.
</Note>

## How connectors appear to an agent

From the agent's perspective, every active connector — built-in or MCP — is simply a **tool** available during a conversation. When you ask the agent to do something that needs an external service, it picks the appropriate tool, calls it, and folds the result into its reply. You do not need to invoke tools manually.
