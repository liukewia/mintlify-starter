Octop includes two advanced interfaces — **Browser AI+** for headless Chromium web automation, and **Terminal AI+** for shell access with AI assistance. Both are available directly in the web dashboard and extend what your agents can do beyond text conversations.

---

## Browser AI+

Browser AI+ gives your agents a real browser to work with. Under the hood it uses harness-browser, a CDP-based automation library with persistent profiles.

### What Browser AI+ can do

- Run headless Chromium sessions for web automation tasks
- Take screenshots of any URL
- Fill out forms, click buttons, and navigate web pages
- Stream a live remote desktop view you can watch and control from the dashboard
- Spin up an isolated desktop environment with one click on headless Linux servers (useful for GUI applications on cloud VMs)

### Enable Browser AI+

Browser AI+ requires the `browser` extra. Install it using the method that matches how you installed Octop:

<CodeGroup>
```bash One-line installer (macOS / Linux)
curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras browser
```

```bash PyPI
pip install "octop[browser]"
```
</CodeGroup>

After installation, restart `octop run`. The browser skill becomes available to agents automatically.

### Use Browser AI+ in chat

Ask your agent to browse in plain language. For example:

- *"Go to news.ycombinator.com and give me the top 5 headlines."*
- *"Take a screenshot of https://example.com."*
- *"Fill in the sign-up form at [URL] with these details…"*

### Remote desktop

Open the **Remote Desktop** panel in the dashboard to view and control a live screen. This works on Linux, Windows, and macOS. On a headless Linux server, click **Launch Desktop** to create an isolated desktop session without needing a physical display.

## Terminal AI+

Terminal AI+ embeds an interactive shell session in your browser dashboard, so you can run commands and get AI assistance without switching to a separate terminal application.

### What Terminal AI+ can do

- Open a full interactive shell session in the browser
- Ask the agent to suggest commands, explain output, or diagnose errors
- Run commands directly with AI guidance

### Shell guardrails

Octop enforces user-editable allow and deny rules before executing shell commands. These rules live in:

```
~/.octop/security/tool_guard/
```

Edit the files in that directory to control which commands your agents are permitted to run automatically and which require approval.

<Note>
  Agents can be configured to require manual approval before running any shell command. Enable the **tool approval** setting in your agent's configuration to review every command before execution — this is the safest option for agents with broad access.
</Note>

<Warning>
  Review the allow/deny rules in `~/.octop/security/tool_guard/` before enabling shell access in a production environment. Overly permissive rules could allow an agent to run destructive or unintended commands. Start with a restrictive allowlist and expand it only as needed.
</Warning>
