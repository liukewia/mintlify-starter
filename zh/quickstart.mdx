Octop 是一个自托管的多用户 AI 助手平台，完全运行在您自己的机器上。在本指南中，您将安装 `octop` CLI，运行 `octop init`，启动服务器，完成首次设置向导，并发送第一条消息——整个过程不到五分钟。

<Steps>
  <Step title="安装 Octop">
    选择适合您平台的安装方式。每种方法都会在 `~/.octop/venv` 处配置一个隔离环境，并通过 `~/.octop/bin` 将 `octop` 添加到您的 PATH 中——无需系统 Python。

    <CodeGroup>

    ```bash macOS / Linux
    curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash
    ```

    ```powershell Windows (PowerShell)
    irm https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.ps1 | iex
    ```

    ```bat Windows (cmd)
    curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.bat -o install.bat
    install.bat
    ```

    ```bash PyPI（已有 Python 环境）
    pip install octop
    ```

    </CodeGroup>
  </Step>
  <Step title="重新加载 shell">
    打开**新的终端**，或重新加载当前 shell 会话，以便 PATH 能够识别 `~/.octop/bin`：

    <CodeGroup>

    ```bash Zsh
    source ~/.zshrc
    ```

    ```bash Bash
    source ~/.bashrc
    ```

    </CodeGroup>

    <Note>
      在 Windows 上，安装程序会自动更新用户 PATH——关闭并重新打开终端以使更改生效。无需执行 shell 重载命令。
    </Note>

    确认安装成功：

    ```bash
    octop --version
    ```
  </Step>
  <Step title="初始化 Octop">
    初始化本地环境：

    ```bash
    octop init
    ```

    这会准备好 `~/.octop/`（数据库、密钥等相关文件）。所有数据都保留在您机器的 `~/.octop/` 目录下。
  </Step>
  <Step title="启动服务器">
    在前台启动 Octop：

    ```bash
    octop run
    ```

    看到服务器就绪消息后，打开浏览器并访问：

    ```text
    http://127.0.0.1:8088
    ```

    首次启动时，页面会进入**设置向导**。请先到用户主目录打开 `~/octop-login.txt`，将其中的一次性设置密码粘贴到向导中，然后自行设置管理员用户名和密码。

    <Note>
      该文件位于用户主目录的 `~/octop-login.txt`，不在 `~/.octop/` 下。设置完成后文件会被删除，之后请使用您自设的用户名和密码登录。
    </Note>

    如需绑定所有网络接口或使用不同端口，直接传递参数即可：

    ```bash
    octop run --host 0.0.0.0 --port 9000
    ```

    如需将 Octop 作为持久后台服务运行（systemd、launchd 或 Windows Service），请使用：

    ```bash
    octop service start
    ```
  </Step>
  <Step title="配置模型提供商">
    Octop 内置了腾讯云、OpenAI、Anthropic、DeepSeek、Ollama 等大量预设。在页面中添加您的第一个提供商：

    ```text
    管理 → 模型
    ```

    <Frame>
      ![模型管理](/images/ui-models.png "模型管理")
    </Frame>

    选择一个预置提供商，填入 API 密钥并启用。它的模型会进入可用模型池，供您账户下的所有专家使用。

    <Tip>
      更习惯终端？使用 `octop models config`——详见 [专家命令](/zh/cli/agent-commands#octop-models)。
    </Tip>
  </Step>
  <Step title="开始聊天">
    打开页面的**聊天**，地址为 `http://127.0.0.1:8088`。选择您的专家（设置向导会创建一个默认的 `main` 专家）并发送第一条消息。

    <Frame>
      ![聊天](/images/ui-chat.png "聊天")
    </Frame>

    从现在开始，您的专家将能够使用您配置的所有技能、连接器和工具。

    <Tip>
      终端交互式聊天见 [`octop chats`](/zh/cli/agent-commands#octop-chats)。
    </Tip>
  </Step>
</Steps>

<Note>
  基础安装程序会设置核心平台。如需解锁额外功能，请使用 `--extras` 参数重新运行安装程序：

  ```bash
  # 浏览器自动化（Playwright Chromium）
  curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras browser
  
  # 飞书渠道支持
  curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras channels-feishu
  ```

  浏览器自动化支持无头 Chromium 会话，用于网页任务和截图。飞书扩展添加了一个渠道桥接，让您的专家能够接收和回复飞书消息。
</Note>

<Tip>
  对于生产部署或多用户环境，请使用 Docker Compose 而非裸机安装。请参阅 [Docker 部署指南](/zh/quickstart-docker)，通过单个 `docker compose` 命令让 Octop 运行起来，支持持久化卷和便捷的环境变量配置。
</Tip>
