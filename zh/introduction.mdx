Octop是一个您自己托管的开源AI助手。它为您提供一套 Web 页面、一个 CLI 以及消息平台集成（飞书、企业微信、钉钉、QQ、微信、Telegram 等）——所有这些都在单个进程中运行，每次对话和凭据都存储在您自己机器的 `~/.octop/` 目录下。

## 您可以用Octop做什么

- **与专业专家聊天**——为每个用户创建多个专家，每个专家拥有自己的LLM提供商、技能组合和MBTI人格设定
- **连接您的消息应用**——将来自飞书、企业微信、钉钉、QQ、微信、Telegram 等平台的对话路由至您的专家
- **安排自动化任务**——设置定时任务，按计划提示您的专家
- **对接编程智能体**——通过 ACP 接入 OpenCode、CodeBuddy、Claude Code 或 Codex
- **实现网页自动化**——内置浏览器工作台、终端与远程桌面
- **保持私密性**——不依赖云服务；所有数据均存储在您的机器上
