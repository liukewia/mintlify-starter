使用专家 API 创建、配置、启动、停止并重新加载 Octop 专家。每个专家都拥有自己的持久化状态、模型配置和人格。

## 基地路径

```text
/api/agents
```

## 端点

| 方法 | 路径 | 描述 |
| --- | --- | --- |
| GET | `/agents` | 列出所有专家 |
| POST | `/agents` | 创建新专家 |
| GET | `/agents/{id}` | 获取单个专家详情 |
| PATCH | `/agents/{id}` | 更新专家配置 |
| DELETE | `/agents/{id}` | 删除专家 |
| POST | `/agents/{id}/start` | 启动专家运行时 |
| POST | `/agents/{id}/stop` | 停止专家运行时 |
| POST | `/agents/{id}/reload` | 重新加载专家配置 |
| POST | `/agents/{id}/read` | 将频道标记为已读 |
| GET | `/agents/{id}/status` | 获取运行时状态 |
| POST | `/agents/from-expert/{expert_id}` | 从专家模板创建专家 |

## 列出专家

```bash
curl http://127.0.0.1:8088/api/agents \
  -H 'Authorization: Bearer <token>'
```

## 创建专家

```bash
curl -X POST http://127.0.0.1:8088/api/agents \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "客服助手",
    "persona_mbti": "ENFJ",
    "default_model": "gpt-4o",
    "description": "处理客户支持请求的专家"
  }'
```

### 请求字段

<ParamField body="name" type="string" required>
  专家的人类可读名称。
</ParamField>

<ParamField body="persona_mbti" type="string">
  旋定专家行为风格的 MBTI 人格代码（例如 `"ENFP"`）。
</ParamField>

<ParamField body="default_model" type="string">
  默认用于此专家对话的模型名称。
</ParamField>

<ParamField body="system_prompt" type="string">
  自定义系统提示词，覆盖默认行为。
</ParamField>

<ParamField body="description" type="string">
  专家用途的简短描述。
</ParamField>

<ParamField body="template_name" type="string">
  创建专家时应用的可选模板名称。
</ParamField>

## 启动与停止

启动或停止专家的运行时：

```bash
curl -X POST http://127.0.0.1:8088/api/agents/1/start \
  -H 'Authorization: Bearer <token>'

curl -X POST http://127.0.0.1:8088/api/agents/1/stop \
  -H 'Authorization: Bearer <token>'
```

成功时两个端点都返回 `204 No Content`。通过 `/status` 端点检查实际运行状态：

```bash
curl http://127.0.0.1:8088/api/agents/1/status \
  -H 'Authorization: Bearer <token>'
# {"state": "running", "last_error": null, ...}
```

## 重新加载专家

在修改配置后重建专家运行时，而无需完全重启：

```bash
curl -X POST http://127.0.0.1:8088/api/agents/1/reload \
  -H 'Authorization: Bearer <token>'
```

<Note>
  若该专家当前有正在进行的操作（例如正在处理对话轮次），重新加载请求将返回 `409 AGENT_BUSY`。请在重试前等待当前操作完成。
</Note>

## 从专家模板创建

Octop 提供预制的专家模板，可以快速引导创建新专家：

```bash
curl -X POST http://127.0.0.1:8088/api/agents/from-expert/finance-advisor \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{"name": "我的理财助手"}'
```

通过 `GET /api/experts` 获取可用专家模板目录。

## MBTI 人格代码

Octop 使用 MBTI 人格代码来旋定专家的沟通风格。

列出所有可用代码：

```bash
curl http://127.0.0.1:8088/api/mbti/codes \
  -H 'Authorization: Bearer <token>'
```

获取单个代码的详情：

```bash
curl http://127.0.0.1:8088/api/mbti/codes/ENFP \
  -H 'Authorization: Bearer <token>'
```

将人格应用到现有专家并重新加载：

```bash
curl -X PUT http://127.0.0.1:8088/api/agents/1/mbti \
  -H 'Authorization: Bearer <token>' \
  -H 'Content-Type: application/json' \
  -d '{"code": "ENFP"}'
```
