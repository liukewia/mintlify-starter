Octop 包含两项高级能力：**浏览器 AI\+**（用于网页自动化和截图）以及**终端 AI\+**（用于 Web 仪表盘中的 AI 辅助命令执行）。

## 浏览器 AI\+

浏览器 AI\+ 内置了无头 Chromium 会话，让智能体可以：

- 浏览网页并提取内容
- 填写表单并与页面交互
- 截取屏幕截图作为回复的一部分

启用浏览器 AI\+ 需要安装带有 `browser` 扩展的 Octop：

```bash
curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras browser
```

启用后，智能体可以在对话中直接调用浏览器技能：

```bash
octop agent skill enable my-agent --skill browser
```

## 终端 AI\+

终端 AI\+ 在 Web 仪表盘中内建了一个终端会话面板，让智能体可以代表您执行 shell 命令。这对于自动化系统管理任务、运行脚本或调试服务很有用。

```bash
octop agent skill enable my-agent --skill terminal
```

<Warning>
  终端 AI\+ 让智能体能够在您机器上执行任意命令。仅在信任的智能体和可控的环境中启用此技能。
</Warning>

<Tip>
  可以在 Web 仪表盘中实时观察浏览器会话和终端会话的实际执行过程，方便调试和审核智能体的行为。
</Tip>
