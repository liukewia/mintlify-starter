Octop 的**工作台**把远程浏览器和 AI 辅助终端合并在一个页面，让您实时查看并随时接管专家的执行过程。另有独立的**远程桌面**页面，用于操控主机的图形桌面。

## 浏览器

浏览器标签页驱动的是一个真实的 Chromium 实例（通过 CDP 接入，支持持久化配置），专家可以在其中浏览网页、填写表单、截图，您也可以随时接管操作。

### 启用浏览器

浏览器需要 `browser` 扩展，按您的安装方式选择：

<CodeGroup>
```bash 一键安装脚本（macOS / Linux）
curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras browser
```

```bash PyPI
pip install "octop[browser]"
```
</CodeGroup>

安装后重启 `octop run`，然后打开：

```text
工作台 → 浏览器
```

点击**检查**确认环境就绪，再点击**启动浏览器**建立会话。在地址栏输入网址即可访问，同时可使用收藏夹与 AI 助手。

<Frame>
  ![工作台浏览器](/images/ui-workbench.png "工作台浏览器")
</Frame>

启用后，在对话中直接用自然语言让专家浏览网页即可，例如「帮我看看某某网站今天的头条」或「给 https://example.com 截个图」。

## 终端

终端标签页在页面中内嵌了完整的交互式 shell，标签名为**终端 AI+**。您可以开多个标签、直接执行命令，也可以让专家推荐命令、解释输出或排查报错。

```text
工作台 → 终端
```

<Frame>
  ![工作台终端](/images/ui-terminal.png "工作台终端")
</Frame>

## 远程桌面

**远程桌面**用于查看并操控 Octop 主机的操作系统桌面。点击**检查**确认环境，再点击**连接**建立会话，之后即可在画面中点击、拖动与输入。

<Frame>
  ![远程桌面](/images/ui-remote-desktop.png "远程桌面")
</Frame>

## 安全防护

浏览器和终端让专家能够真实触达您的机器，因此相关的安全控制统一收敛在：

```text
管理 → 安全防护
```

<Frame>
  ![安全防护](/images/ui-security.png "安全防护")
</Frame>

页面分为六个标签页：

| 标签页 | 作用 |
| --- | --- |
| **工具审批** | 命中列表的工具在执行前暂停，等待您在对话中批准或拒绝 |
| **文件访问** | 控制专家可读写的路径 |
| **敏感信息** | 对密钥和个人信息做脱敏处理 |
| **命令防护** | 对 shell 命令生效的放行与拦截规则 |
| **技能扫描** | 技能安装前的安全检查 |
| **审计日志** | 记录被防护拦截或放行的操作 |

工具审批默认已把风险最高的 `bash`、`execute`、`write_file`、`edit_file` 列入名单，但总开关**启用工具人工审批**默认关闭。打开后，名单中的工具执行前都会等待您确认。

保存时会一并保存所有标签页的设置，运行中的专家会自动重载。

<Warning>
  在生产环境开放 shell 访问前，请先检查命令防护和文件访问规则。过于宽松的规则可能让专家执行破坏性命令。建议从严格的白名单开始，按需逐步放开。
</Warning>

<Tip>
  启用技能的 CLI 命令见[专家命令](/zh/cli/agent-commands#octop-skills)。
</Tip>
