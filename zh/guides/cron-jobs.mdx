为您的 Octop 专家设置定时任务，让它们自动发送提醒、报告或定时执行其他任务，无需手动触发。

## 创建定时任务

<CodeGroup>

```bash 使用 cron 表达式
octop cron add --agent my-agent --schedule "0 9 * * *" --prompt "总结昨天的新闻"
```

```bash 使用自然语言
octop cron add --agent my-agent --schedule "每天上午 9 点" --prompt "总结昨天的新闻"
```

</CodeGroup>

## 触发类型

- **Cron 表达式** —— 标准 5 字段 cron 语法，适用于重复性计划
- **间隔** —— 每 N 小时/分钟执行一次
- **一次性日期** —— 在特定时间点执行一次

## 管理定时任务

```bash
# 列出所有定时任务
octop cron list

# 暂停一个定时任务
octop cron pause <job-id>

# 删除一个定时任务
octop cron delete <job-id>
```

<Note>
  定时任务触发时，专家会像处理普通消息一样处理提示——它可以调用技能、访问连接器，并将结果发送到其已配置的渠道。
</Note>

<Tip>
  将定时任务与 IM 渠道结合，可以实现每天自动推送报告到飞书或 Discord 频道，无需人工干预。
</Tip>
