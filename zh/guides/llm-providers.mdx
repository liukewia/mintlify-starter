Octop 支持 OpenAI 兼容 API、DashScope（通义千问）、Ollama 以及任何其他兼容 OpenAI 接口规范的提供商。您可以为每个智能体单独配置提供商，享可以设置全局默认提供商。

## 添加提供商

<CodeGroup>

```bash CLI
octop provider add --name openai --api-key sk-...
```

```text 仪表盘
设置 → 提供商 → 添加提供商
```

</CodeGroup>

## 支持的提供商预设

| 提供商 | 描述 |
| --- | --- |
| OpenAI | 官方 OpenAI API |
| DashScope | 阿里云通义千问 |
| Ollama | 本地部署的开源模型 |
| 自定义 | 任何兼容 OpenAI API 规范的端点 |

## 为智能体设置模型

添加提供商后，为特定智能体指定它使用的模型：

```bash
octop agent model set my-agent --provider openai --model gpt-4o
```

若未为智能体指定，它将使用您设置的全局默认提供商和模型。

<Tip>
  不同智能体可以使用不同的提供商和模型——例如用便宜的模型处理日常对话，用更强大的模型处理复杂任务。
</Tip>

## 使用 Ollama

如果您在本地运行 Ollama，将其添加为提供商时无需 API 密钥：

```bash
octop provider add --name ollama --base-url http://localhost:11434
```
