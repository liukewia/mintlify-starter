Octop 支持 OpenAI 兼容 API、DashScope（通义千问）、Ollama 以及任何其他兼容 OpenAI 接口规范的提供商。您可以为每个专家单独配置提供商，享可以设置全局默认提供商。

## 添加提供商

设置 → 提供商 → 添加提供商

<Frame>
  ![Add Provider](/images/add-provider.png "Add Provider")
</Frame>

```text 仪表盘
设置 → 提供商 → 添加提供商
设置 → 提供商 → 添加提供商
```

## 支持的提供商预设

| 提供商 | 描述 |
| --- | --- |
| OpenAI Compatible | OpenAI 兼容 API |
| Anthropic Messages | Anthropic Messages API |
| 自定义 | 任何兼容 OpenAI 兼容 API 规范的端点 |

## 为专家设置模型

添加提供商后，为特定专家指定它使用的模型：

<Frame>
  ![Agent Select Model](/images/agent-select-model.png "Agent Select Model")
</Frame>

若未为专家指定，它将使用您设置的全局默认提供商和模型。

<Tip>
  不同专家可以使用不同的提供商和模型——例如用便宜的模型处理日常对话，用更强大的模型处理复杂任务。
</Tip>

## 使用 Ollama

如果您在本地运行 Ollama，将其添加为提供商时无需 API 密钥。
