连接器为 Octop 专家扩展了访问外部服务和工具的能力。Octop 把连接器分为两类：**内置连接器**（一次授权即可使用的现成集成）和**自定义连接器**（您自己接入的 MCP 服务器）。连接器是账户级配置，对话时按需勾选要用的连接器。

</Frame>

## 内置连接器

Octop 目前内置 18 个连接器：

| 连接器 | 能力 |
| --- | --- |
| **腾讯文档** | 读写腾讯文档、智能表格与空间文件 |
| **腾讯 IMA** | 笔记与知识库读写、检索与管理 |
| **腾讯会议** | 会议管理、查询、录制与智能纪要 |
| **腾讯新闻** | 新闻搜索与热点订阅 |
| **微信读书** | 书架同步与读书笔记 |
| **腾讯乐享** | 知识库检索、阅读、创建与文档管理 |
| **腾讯微云** | 官方 MCP：网盘列表、上传、下载、分享与文件管理 |
| **个人邮箱** | 通过 IMAP/SMTP 连接 QQ 邮箱、网易邮箱、Gmail 等 |
| **QQ 音乐** | 搜歌、排行榜、歌单与听歌报告 |
| **飞猪** | 机票、酒店、景点与行程智能搜索 |
| **百度地图** | 地点检索、路线规划与天气查询 |
| **携程问道** | 酒店、机票与行程问答推荐 |
| **美团旅游助手** | 酒店、机票、火车票、景点与行程问答 |
| **元典** | 法律法规、案例文书、企业信息与法律幻觉检测 |
| **有道云笔记** | 官方 MCP：笔记创建、搜索、整理与管理 |
| **Notion** | 官方 MCP：搜索、读写页面与数据库 |
| **飞书 CLI** | 通过官方 `lark-cli` 操作文档、多维表格、日历与消息（需主机安装 CLI） |
| **企业微信 CLI** | 通过官方 `wecom-cli` 操作文档、日程与消息（需主机安装 CLI） |

在页面中连接：

```text
连接器 → 内置连接器 → 点击连接
```

授权后，Octop 会把令牌保存在本机 `~/.octop/secrets/` 下，不会离开您的机器。

## 自定义连接器（MCP）

MCP（Model Context Protocol）是连接 AI 智能体与外部工具服务器的开放标准。在**连接器 → 自定义连接器**中，您可以用可视化表单或直接粘贴 JSON 来注册任意兼容 MCP 的服务器：

```json
{
  "deepwiki": {
    "display_name": "DeepWiki",
    "url": "https://mcp.deepwiki.com/mcp",
    "transport": "streamable_http"
  }
}
```

支持两种服务器类型：

| 类型 | 适用场景 |
| --- | --- |
| **HTTP Server** | MCP 服务器通过 URL 访问（如 `streamable_http`） |
| **Stdio Server** | MCP 服务器是由 Octop 拉起的本地进程 |

<Note>
  Stdio 类型的服务器需要安装在运行 `octop run` 的机器上；HTTP 类型的服务器需要能从该机器访问到。
</Note>

## 专家如何使用连接器

从专家的视角看，每个启用的连接器——无论内置还是 MCP——都只是对话中可调用的一个**工具**。当您的请求需要用到外部服务时，专家会自行选择合适的工具、调用它，并把结果融入回复。您不需要手动触发。

<Tip>
  如果生态中没有现成的 MCP 服务器，可以自己搭建一个并通过自定义连接器接入。
</Tip>
