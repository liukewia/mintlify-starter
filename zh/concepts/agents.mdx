专家是 Octop 的核心工作单元。每个专家都是一个独立配置的 AI 助手，拥有自己的工作区目录、LLM 提供商设置、已启用技能、连接的 IM 渠道以及对话历史。

## 专家的组成

- **工作区** —— 专家专属的文件目录，用于存放它生成或处理的文件
- **LLM 提供商** —— 该专家使用的模型和 API 凭据
- **技能** —— 该专家可以调用的能力（如网页浏览、终端访问）
- **通道** —— 连接到该专家的消息平台（飞书、企业微信、Telegram 等）
- **人格** —— 可选的 MBTI 人格或专家模板，用于塑造沟通风格
- **对话历史** —— 该专家所有会话的持久化记录

## 创建专家

在页面中打开**专家**，页面分为**我的专家**、**内置专家**和**专家市场**三个标签页，点击**从内置专家新建**可以基于模板一键创建。

<Frame>
  ![专家列表](/images/ui-agents.png "专家")
</Frame>

`octop init` 会自动创建一个默认的 `main` 专家，您可以立即开始与它对话。

<Tip>
  通过 CLI 创建、列出、启动、停止和重载专家，请参阅 [专家命令](/zh/cli/agent-commands)。
</Tip>

## 管理多个专家

每个用户账户下可以创建任意数量的专家，彼此完全隔离。这适用于以下场景：

- 为不同项目或客户创建专用专家
- 为不同的通道分配不同的专家
- 让不同专家使用不同的 LLM 提供商或人格设定

## 按专家配置

技能、子智能体、人格、记忆和通道都在**个性化**中按专家配置。在页面顶部选择专家后，切换对应标签页：

| 标签页 | 配置内容 |
| --- | --- |
| **技能** | 已安装技能、内置技能、技能市场与技能包 |
| **子智能体** | 该专家可委派的辅助智能体 |
| **MBTI** | 决定语气与思考风格的人格设定 |
| **记忆** | 专家跨对话保留的信息 |
| **通道** | 路由到该专家的消息平台 |

<Tip>
  如果您需要让专家具备特定的沟通风格或专业领域知识，请参阅[专家与人格](/zh/concepts/experts-personas)，了解如何应用内置模板。
</Tip>
