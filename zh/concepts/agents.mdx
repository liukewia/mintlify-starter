智能体是 Octop 的核心工作单元。每个智能体都是一个独立配置的 AI 助手，拥有自己的工作区目录、LLM 提供商设置、已启用技能、连接的 IM 渠道以及对话历史。

## 智能体的组成

- **工作区** —— 智能体专属的文件目录，用于存放它生成或处理的文件
- **LLM 提供商** —— 该智能体使用的模型和 API 凭据
- **技能** —— 该智能体可以调用的能力（如网页浏览、终端访问）
- **渠道** —— 连接到该智能体的 IM 平台（飞书、Discord 等）
- **人格** —— 可选的 MBTI 人格或专家模板，用于塑造沟通风格
- **对话历史** —— 该智能体所有会话的持久化记录

## 创建智能体

您可以通过 Web 仪表盘或 CLI 创建智能体：

<CodeGroup>

```bash CLI
octop agent create --name my-agent
```

```text 仪表盘
智能体 → 新建智能体
```

</CodeGroup>

`octop init` 会自动创建一个默认的 `main` 智能体，您可以立即开始与它对话。

## 管理多个智能体

每个用户账户下可以创建任意数量的智能体，彼此完全隔离。这适用于以下场景：

- 为不同项目或客户创建专用智能体
- 为不同的 IM 渠道分配不同的智能体
- 让不同智能体使用不同的 LLM 提供商或人格设定

列出您当前账户下的所有智能体：

```bash
octop agent list
```

<Tip>
  如果您需要让智能体具备特定的沟通风格或专业领域知识，请参阅[专家与人格](/zh/concepts/experts-personas)，了解如何应用内置模板。
</Tip>
