Octop 提供两种方式来塑造智能体的“个性”：**MBTI 人格模板**用于调整沟通风格和思维方式，**专家模板**用于赋予智能体特定领域的专业知识框架。

## MBTI 人格模板

Octop 内置全部 16 种 MBTI 人格类型模板（如 INTJ、ENFP 等）。为智能体分配一种人格后，它的回复语气、决策方式和沟通风格都会随之调整，同时保留其原有的技能和知识。

<CodeGroup>

```bash CLI
octop agent persona set my-agent --persona INTJ
```

```text 仪表盘
智能体 → 选择智能体 → 人格 → 选择 MBTI 类型
```

</CodeGroup>

## 专家模板

专家模板是预先配置好的角色设定，为智能体提供特定领域的视角和工作方法——例如产品经理、代码审查员或数据分析师。应用专家模板会调整智能体处理任务时的默认思路和输出格式。

```bash
octop agent expert set my-agent --expert code-reviewer
```

## 组合使用

人格和专家模板可以同时应用于同一个智能体——人格决定“怎么说”，专家模板决定“从什么角度想”。例如，一个应用了 ENTJ 人格和“产品经理”专家模板的智能体，会以直接、目标驱动的语气给出产品决策建议。

<Note>
  人格和专家设定都是可选的。未设置时，智能体会使用默认的中性沟通风格。
</Note>
