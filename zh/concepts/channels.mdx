通道是 Octop 专家与消息平台之间的桥梁。每个通道连接一个特定平台的账号（如一个飞书机器人）到您的某一个专家，让您可以直接在熟悉的聊天应用中与专家对话。

<Frame>
  ![通道](/images/ui-channels.png "通道")
</Frame>

## 支持的通道

Octop 目前内置 9 个通道：

| 通道 | 说明 |
| --- | --- |
| **微信** | 配置个人微信频道，通过 iLink Bot 接收与回复私聊、群聊消息 |
| **QQ** | 配置 QQ 机器人频道，支持私聊与群聊消息 |
| **企业微信** | 配置企业微信机器人频道，支持应用消息、单聊与群聊场景 |
| **飞书** | 配置飞书机器人频道，支持私聊与群聊，消息双向同步到 Agent |
| **元宝** | 配置腾讯元宝通讯频道，将 Agent 能力接入元宝会话场景 |
| **钉钉** | 配置钉钉机器人频道，支持单聊与群聊，适合团队办公场景 |
| **Telegram** | 配置 Telegram Bot 频道，支持私聊与群组消息经 Bot API 接入 |
| **小艺** | 配置华为小艺（OpenClaw）频道，经 A2A 协议与语音助手互通 |
| **MQTT** | 配置 MQTT 频道，将 IoT 设备或机器人消息路由到 Agent |

<Note>
  页面自带聊天功能，创建专家后无需配置任何通道即可直接对话。
</Note>

## 通道的工作方式

每个通道都是一份独立配置，包含：

- 该平台的凭据（App ID、密钥、Token 等）
- 该通道绑定的目标专家
- 消息路由规则（例如仅响应私聊，或响应特定群组）

添加通道后，来自该平台的消息会被路由到绑定的专家，专家的回复也会通过同一通道发送回去。

在页面中配置通道：

```text
个性化 → 通道
```

在页面顶部选择专家，打开对应平台的开关并填写凭据即可。

<Tip>
  各平台的凭据获取步骤见[设置 IM 通道指南](/zh/guides/im-channels)。CLI 命令见[通道与定时任务](/zh/cli/channel-cron-commands#octop-channel)。
</Tip>

## 一个专家，多个通道

一个专家可以同时连接多个通道——例如同时接入飞书和 Telegram，这样无论用户从哪个平台发消息，都会由同一个专家处理，并共享同一份对话上下文和记忆。
