渠道是 Octop 专家与即时通讯平台之间的桥梁。每个渠道连接一个特定的 IM 平台账户（如一个飞书机器人或一个 Discord Bot）到您的某一个专家，让您可以直接在熟悉的聊天应用中与专家对话。

## 支持的平台

- 飞书
- 钉钉
- QQ
- Discord
- 企业微信

## 渠道的工作方式

每个渠道都是一个独立配置，包含：

- 该 IM 平台的凭据（App ID、密钥、Token 等）
- 该渠道绑定的目标专家
- 消息路由规则（例如仅响应私聊，或响应特定群组）

添加渠道后，来自该 IM 平台的消息会被路由到绑定的专家，专家的回复也会通过同一渠道发送回去。

```bash
octop channel add --platform feishu --agent my-agent
```

<Tip>
  关于每个平台的详细接入步骤（获取凭据、配置回调地址等），请参阅[设置 IM 渠道指南](/zh/guides/im-channels)。
</Tip>

## 一个专家，多个渠道

一个专家可以同时连接多个渠道——例如同时接入飞书和 Discord，这样无论用户从哪个平台发消息，都会由同一个专家处理，并共享同一份对话上下文和记忆。
