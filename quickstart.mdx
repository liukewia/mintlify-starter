Octop is a self-hosted, multi-user AI assistant platform that runs entirely on your own machine. In this guide, you will install the `octop` CLI, run `octop init`, start the server, complete the first-run setup wizard, and send your first message — all in under five minutes.

<Steps>

  <Step title="Install Octop">
    Choose the installer that matches your platform. Every method provisions an isolated environment at `~/.octop/venv` and adds `octop` to your PATH via `~/.octop/bin` — no system Python is required.

    <CodeGroup>

    ```bash macOS / Linux
    curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash
    ```

    ```powershell Windows (PowerShell)
    irm https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.ps1 | iex
    ```

    ```bat Windows (cmd)
    curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.bat -o install.bat
    install.bat
    ```

    ```bash PyPI (existing Python)
    pip install octop
    ```

    </CodeGroup>
  </Step>

  <Step title="Reload your shell">
    Open a **new terminal**, or reload your current shell session so that `~/.octop/bin` is picked up from your PATH:

    <CodeGroup>

    ```bash Zsh
    source ~/.zshrc
    ```

    ```bash Bash
    source ~/.bashrc
    ```

    </CodeGroup>

    <Note>
      On Windows the installer updates your user PATH automatically — close and reopen your terminal to apply the change. No shell reload command is needed.
    </Note>

    Confirm the installation succeeded:

    ```bash
    octop --version
    ```
  </Step>

  <Step title="Initialize Octop">
    Bootstrap your local environment:

    ```bash
    octop init
    ```

    This prepares `~/.octop/` (database, secrets, and related files). All data stays on your machine under `~/.octop/`.
  </Step>

  <Step title="Start the server">
    Launch Octop in the foreground:

    ```bash
    octop run
    ```

    Once you see the server ready message, open your browser and navigate to:

    ```
    http://127.0.0.1:8088
    ```

    On first launch the dashboard opens the **setup wizard**. Open `~/octop-login.txt` in your user home directory, copy the one-time setup password into the wizard, then choose your own admin username and password.

    <Note>
      The file is `~/octop-login.txt` in the user home directory, not under `~/.octop/`. After setup completes, the file is removed and you sign in with the username and password you created.
    </Note>

    To bind on all network interfaces or use a different port, pass flags directly:

    ```bash
    octop run --host 0.0.0.0 --port 9000
    ```

    To run Octop as a persistent background service (systemd, launchd, or Windows Service), use:

    ```bash
    octop service start
    ```
  </Step>

  <Step title="Configure a model provider">
    Octop ships built-in presets for Tencent Cloud, OpenAI, Anthropic, DeepSeek, Ollama, and many more. Add your first provider from the web UI:

    ```text
    Management → Models
    ```

    <Frame>
      ![Model management](/images/ui-models.png "Model management")
    </Frame>

    Pick a built-in preset, enter your API key, and enable it. Its models join the available model pool that every agent under your account can use.

    <Tip>
      Prefer the terminal? Use `octop models config` — see [Agent commands](/cli/agent-commands#octop-models).
    </Tip>
  </Step>

  <Step title="Start chatting">
    Open **Chat** in the web UI at `http://127.0.0.1:8088`. Select your agent (the setup wizard creates a default `main` agent) and send your first message.

    <Frame>
      ![Chat](/images/ui-chat.png "Chat")
    </Frame>

    Your agent now has access to all the skills, connectors, and tools you configure going forward.

    <Tip>
      For an interactive terminal chat session, see [`octop chats`](/cli/agent-commands#octop-chats).
    </Tip>
  </Step>

</Steps>

<Note>
  The base installer sets up the core platform. To unlock additional capabilities, re-run the installer with an `--extras` flag:

  ```bash
  # Browser automation (Playwright Chromium)
  curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras browser

  # Feishu channel support
  curl -fsSL https://finnie-1258344699.cos.ap-guangzhou.myqcloud.com/octop/install.sh | bash -s -- --extras channels-feishu
  ```

  Browser automation enables headless Chromium sessions for web tasks and screenshots. The Feishu extra adds a channel bridge so your agents can receive and reply to Feishu messages.
</Note>

<Tip>
  For production deployments or multi-user setups, use Docker Compose instead of a bare-metal install. See the [Docker Setup guide](/quickstart-docker) to get Octop running with a single `docker compose` command, persistent volumes, and easy environment-variable configuration.
</Tip>
